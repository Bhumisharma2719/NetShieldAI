# NetShield AI

Initial project scaffold:

- `backend/`: FastAPI API connected to PostgreSQL with JWT auth.
- `frontend/`: React + Vite UI with login and role-based dashboards.
- `backend/data/unsw_nb15_sample.csv`: small traffic dataset CSV used by the analyst dashboard.

Start PostgreSQL first, create the `netshield_ai` database, then run backend and frontend from their folders.
